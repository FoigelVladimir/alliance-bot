# Спортивный портал «Альянс»

Поддержка студентов через бота ВК и кабинет менеджеров и руководителя университетского спортивного клуба.

## С чего начать

1. [Навигация по документации](docs/README.md).
2. [Единый план MVP](docs/MVP.md): функционал, сценарии, ограничения и проверки.
3. [Технический черновик](docs/design_draft.md): принятые решения и открытые детали.
4. [Передача коллегам](docs/ПЕРЕДАЧА.md): следующие задачи и границы готовности.

## Состояние

В [apps/frontend](apps/frontend/README.md) есть запускаемая демонстрация первой очереди с синтетическими данными. Настоящие VK ID, сообщения ВК, сервер, база и AI/RAG в ней не подключены.

Для реализации выбраны Python + Django + PostgreSQL, модульная общая серверная система и интерфейс на Django-шаблонах, Tailwind CSS и обычном JavaScript. Спецификация ещё дополняется; выбранная локальная модель требует испытаний. Эти решения не означают, что демонстрация уже использует производственный стек.

Первая очередь — законченная поддержка: вход сотрудника → опубликованный материал → вопрос ВК → ответ бота либо менеджера в том же диалоге. Полный MVP также включает мероприятия, заявки, составы, расписание, посещаемость, рассылки и отчётность; статусы функций — в едином плане.

Бот и веб-обработчики относятся к общей серверной системе, локальная модель запускается отдельно. Каталоги документации не задают независимые сервисы.

## Настройки и работа команды

Секреты, веса модели, рабочие документы, базы, выгрузки и резервные копии не добавляются в Git. `.env.example` предварительный: код его пока не использует.

Рабочая ветка — `dev`. Коммит и перенос в `main` выполняются по согласованному командой порядку. Документы перенесены в `docs/`; пути в старых коммитах сохраняют историческое значение.
