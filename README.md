# Спортивный портал «Альянс»

Рабочий инструмент университетского спортивного клуба: поддержка студентов через бота ВК и кабинет менеджеров и руководителя.

## Структура проекта

```text
apps/
  backend/       Серверная часть, подключение ВК и рабочие модули
  frontend/      Кабинет сотрудников и формы регистрации
docs/            Документация проекта
infra/           Настройки запуска и размещения
.env.example     Пример переменных окружения без секретов
.gitignore       Исключения для локальных данных
README.md        Описание проекта
```

## Состояние

Есть запускаемая демонстрационная сборка кабинета первой очереди в apps/frontend. Она использует синтетические данные без реальных ВК, модели и сервера. Запуск и ограничения описаны в apps/frontend/README.md, передача коллегам — в docs/ПЕРЕДАЧА.md. Производственный стек и техническая спецификация ещё не выбраны.

Первый этап разработки — бот ВК с поиском ответов по опубликованным материалам клуба и передачей обращения менеджеру. Следующие этапы: мероприятия и заявки, составы и отчётность, рассылки, расписание и посещаемость.

Бот и рабочие модули предполагаются частями общей серверной системы. Локальная модель запускается отдельно. Веб-интерфейс обращается к серверу; сервер управляет общей базой и Excel-выгрузками.

## Работа с настройками

После выбора стека дополните `.env.example` необходимыми настройками. Личные значения храните в `.env`; этот файл исключён из Git. Текущие названия переменных предварительные, код их пока не использует.

## Документация и разработка

Назначение каталогов описано в их `README.md`. Исходный план MVP находится в [ветке main](https://github.com/FoigelVladimir/alliance-bot/blob/main/MVP.md); новые решения сначала фиксируются в актуальном рабочем документе.

Каркас подготовлен в ветке `dev`. Порядок проверки и переноса изменений в `main` команда согласует перед началом совместной разработки.
