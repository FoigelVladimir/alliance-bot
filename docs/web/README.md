# Веб-интерфейс

Кабинет менеджеров и руководителя, формы участников и работа с поддержкой.

| Материал | Назначение |
| --- | --- |
| [MVP](../MVP.md), §3.1–3.7 | Пользовательские сценарии и полный объём |
| MVP §20–22 и §25–26 | Направление интерфейса и экраны первой очереди |
| [Технический черновик](../design_draft.md), §9.17 | Django-шаблоны, Tailwind CSS и обычный JavaScript |
| Черновик §10–11 и §12.4 | Поддержка, журнал, черновики и создание материала |

Прототип и демонстрация не определяют серверные права и не доказывают готовность всех экранов. Производственные Django-шаблоны пока не созданы. Их размещение и размещение статических ресурсов предстоит зафиксировать в плане реализации. Существующая демонстрация остаётся в `apps/frontend`.

Публичный медийный сайт отложен; кабинет и регистрационные формы входят в MVP. Требования не меняются только из-за визуального примера.
