Бот — канал общей серверной системы, а не второй владелец составов, мероприятий или прав. Входящий транспорт и отправки отделяются от операций поддержки. Реальное подключение сообщества ВК обязательно для первой очереди; демонстрация его не содержит. Точные контракты событий, повторов и отправок ещё предстоит завершить.
