# Документация проекта

Каталог предназначен для описания архитектуры, взаимодействия частей приложения и инструкций команды по мере подготовки к реализации.

План MVP уже существует в [ветке main](https://github.com/FoigelVladimir/alliance-bot/blob/main/MVP.md). В рабочей папке он обновляется в одном файле `MVP.md`. Дублирующие планы здесь создавать не требуется.

После выбора стека здесь можно описать запуск проекта, форматы обмена данными и принятые технические решения. Подтверждённые требования следует отличать от предложений и непроверенных возможностей внешних сервисов.
