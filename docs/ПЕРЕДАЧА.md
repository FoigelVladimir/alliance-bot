## Следующая законченная задача

Составить техническую спецификацию первого серверного пути: VK ID → одобрение сотрудника → публикация документа → сообщение сообщества ВК → ответ по опубликованным источникам либо общая очередь → один назначенный менеджер → ответ в тот же диалог → завершение.

Определить стек, внутренние идентификаторы, серверную матрицу прав, данные, состояния, версии документов, контракты экранов и исходящие попытки. Выборы фиксировать, а не молча заимствовать из демонстрационного JS. Идентификаторы VK ID и отправителя сообщения не считать одинаковыми без эксперимента.

Домашний ПК: i3-12100F, около 16 ГБ RAM, RTX 3050 8 ГБ; может оставаться включённым. Полный ответ 4–5 секунд ещё не измерен. Нужны реальные материалы/вопросы клуба и доступы ВК. Их отсутствие не заменять вымышленной базой и результатами.

## Разделение работы

Фронтенд: компоненты, адаптация, состояния загрузки/ошибок и подключение согласованного API. Браузер не источник полномочий.

Сервер: VK ID/сессии, проверка каждого действия, общая база, один владелец обращения, история, версии документов, идемпотентность, неизвестный исход отправки и повторные события ВК.

Поиск/модель: только подготовленные опубликованные источники, диагностика версий, измерение качества/задержки, честный отказ, пауза AI после передачи людям.

Запуск: выбрать реальный способ доступа, автозапуск, копии и восстановление. Локальный HTTP-сервер предназначен только для просмотра.
