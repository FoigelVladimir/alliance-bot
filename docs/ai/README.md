# RAG и локальные модели

Навигация по решениям о материалах, поиске и запуске модели. Веса и рабочие документы в этом каталоге не хранятся.

| Предмет | Источник |
| --- | --- |

| Загрузка, проверка, версии и публикация | MVP §3.1; черновик §9.14–9.16 |
| Excel и Google как источники знаний | Черновик §9.14–9.16 |
| Поиск, запуск модели и embedding-модель | Черновик §9.20–9.22 |
| Стартовая компоновка и испытания | Черновик §9.23 |
| Защита от устаревшего AI-ответа | Черновик §9.5 и §11.6 |
| Журнал ответов и пометка проблемы | Черновик §10.8 |
| Обращение → проверенный материал | Черновик §12.4 |

Компоновка выбрана для испытаний. Ответ за 4–5 секунд ещё нужно проверить на доступном ПК с реальными материалами и нагрузкой. Точные версии и параметры будут зафиксированы в основном черновике; список моделей здесь не дублируется.

Модели данных Django описывают рабочие записи; модели AI имеют отдельные веса и среду запуска. Поэтому документация AI находится в `docs/ai`, веса — вне Git. Запуск и обслуживание относятся к [infra](../../infra/README.md).
