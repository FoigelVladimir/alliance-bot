Компоновка выбрана для испытаний. Ответ за 4–5 секунд ещё нужно проверить на доступном ПК с реальными материалами и нагрузкой. Точные версии и параметры будут зафиксированы в основной спецификации; список моделей здесь не дублируется.

Модели данных Django описывают рабочие записи; модели AI имеют отдельные веса и среду запуска. Поэтому документация AI находится в `docs/ai`, веса — вне Git. Запуск и обслуживание относятся к [infra](../../infra/README.md).
