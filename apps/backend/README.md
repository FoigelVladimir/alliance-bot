# Серверная часть

Общая система на Python + Django + PostgreSQL. Выбрана модульная организация одного приложения: бот, веб-обработчики и фоновые исполнители используют общие операции и правила. Базовые зависимости этапа 1А зафиксированы в [requirements.txt](requirements.txt). Серверный проект и миграции описаны в плане §29.

## Базовые зависимости

Из корня репозитория:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r apps/backend/requirements.txt
.venv/bin/python -m pip check
```

Установка и загрузка адаптера PostgreSQL проверены на Python 3.14.5 в macOS.

Каталоги и файлы по этапам перечислены в §29. Проверенные команды запуска оформляются при реализации этапа 1А. Пустые `bot`, `web`, `models` здесь заранее не создаются. Бизнес-правила не дублируются между ВК и веб-интерфейсом; полные требования остаются в документации.
