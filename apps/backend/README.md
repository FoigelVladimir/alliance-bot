# Серверная часть

Общая серверная система для бота ВК, кабинета сотрудников и регистрации участников.

Планируемые обязанности:

- Вход сотрудников, проверка полномочий и справочники.
- Подключение ВК: сообщения, ответы сотрудников и отправка приглашений.
- Материалы базы знаний, поиск и обращение к локальной модели.
- Очередь обращений и передача диалога менеджеру.
- Регистрация, мероприятия, составы, занятия и посещаемость.
- Сводки руководителю, контроль заполнения и Excel-выгрузки.
- Фоновые задания и видимые ошибки обработки.

Это модули одного приложения, а не обязательные отдельные сервисы. Внутренние папки исходного кода, зависимости, миграции базы и команды запуска появятся после выбора языка и фреймворка.

Начинаем с законченного сценария поддержки: публикация материала → вопрос в ВК → ответ по материалу или передача сотруднику → ответ сотрудника в тот же диалог.
