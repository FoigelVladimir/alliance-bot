# Веб-интерфейс

Здесь будет кабинет сотрудников с разными правами менеджера и руководителя, а также страницы регистрации, если команда утвердит собственную форму.

Планируемые разделы кабинета: обращения, база знаний, мероприятия и заявки, составы, расписание и посещаемость, рассылки, сводки и выгрузки.

Интерфейс получает сведения от серверной части. Проверки доступа и сохранение рабочих данных выполняются сервером.

Первый экранный сценарий — управление материалами бота и работа с обращениями, переданными менеджеру. Публичный медиасайт отложен.

Исходный код, зависимости и команды запуска появятся после выбора средств разработки интерфейса.
