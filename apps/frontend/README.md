# Кабинет поддержки: демонстрационная сборка

Шесть представлений первой очереди из §26 MVP: вход/статус доступа, главная, обращения, база знаний, материал, сотрудники. Нативные HTML/CSS/JavaScript без сборщика и устанавливаемых библиотек. Это демонстрация сценариев; выбранный для рабочей версии стек Django-шаблонов/Tailwind/обычного JavaScript здесь ещё не реализован.

## Запуск из корня репозитория

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory apps/frontend
```

Открыть http://127.0.0.1:8766. Через file:// не запускать: используются ES-модули. Остановка — Ctrl+C. Сервер доступен только на текущем компьютере и не предназначен для публикации пилота. Для Manrope используется Google Fonts; без сети доступен запасной системный шрифт.

## Три прохода

1. Главная → свободное обращение → взять в работу → поиск по слову «занятий» → вставить источник → сохранить демоответ → закрыть.
2. База знаний → добавить тестовый текст → сохранить черновик → опубликовать. Проверить поиск. Снять публикацию и повторить поиск. Неопубликованная новая версия не заменяет действующую.
3. Переключить профиль на Анну: ожидание доступа. Переключить на Ольгу → сотрудники → одобрить Анну. Вернуться к Анне. Блокировка закрывает рабочие представления профиля.

Только синтетические данные в localStorage браузера, ключ `alliance-support-demo-v1`. «Сбросить демо» восстанавливает примеры. Настоящих сообщений ВК нет. Документ — текст или .txt до 200 КБ, не реальный договорённый набор форматов. Не загружать личные данные.

## Проверки

С установленным Node.js, из этой папки:

```powershell
node --check app.js
node --check store.js
node --test store.test.js
```

Установка пакетов и npm не нужны. Проверки охватывают доступ к ответу и исключение неопубликованного/снятого источника из поиска. Они не доказывают безопасность будущего сервера.

## Ограничения

Спецификация поддержки обновлена 2 ноября: два статуса «Открыто»/«Закрыто», назначение отдельно, без стороны ожидания и промежуточного типа ответа; предусмотрен явный перехват у коллеги. См. [черновик](../../docs/design_draft.md), §11.4–11.6 и §14.2. Данная статическая демонстрация под эти изменения ещё не адаптирована; её состояния не заменяют актуальные требования.

Нет настоящих VK ID, сервера, базы, AI/RAG, отправки ВК, многопользовательской синхронизации, журнала, фоновых задач и мониторинга. Роли сверху — явный демонстрационный переключатель, не авторизация. Поиск по словам локальный. Права и хранение должны проверяться сервером в рабочей версии.

Черновик ответа удерживается в памяти до перезагрузки. Несохранённые изменения материала могут теряться при переключении раздела; постоянное сохранение черновиков не реализовано. Турниры, секции, посещаемость, рассылки и отчёты ещё не реализованы. [Исходный прототип](../../docs/design/прототип_интерфейса.html) — визуальный референс.
